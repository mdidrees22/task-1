## Description

NestJS backend for Spatium Nexum. Features a robust authentication flow with JWT, secure password hashing, and a multi-database PostgreSQL architecture.

---

## ⚠️ Important Configuration

**Please make a `.env` file before running the project.** Ask Mohd Idrees for the `.env` file and place it in the root directory. The application will not connect to the Supabase databases or send emails without it.

---

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
